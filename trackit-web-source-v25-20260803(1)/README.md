# 振动分析系统

基于YOLOv8-Tiny的纯前端振动分析软件，支持视频上传、物体识别、坐标系标定、数据采集、神经网络训练、振动参数计算和可视化展示。

## 🚀 运行方式

**方式一：Web 版（推荐开发调试）**
1. 将整个文件夹下载到本地
2. `python -m http.server 8000` 或 `python serve.py`（后者附带多线程推理头）
3. 用 **Chrome 或 Edge 最新版** 打开 http://localhost:8000
4. 完全离线可用（库/wasm/模型均已本地化，无 CDN 依赖）

**方式二：离线 EXE（交付客户）**
1. 直接运行 `dist/VibrationAnalysis-Offline-1.0.0.exe`（单文件，无需安装）
2. 或重新打包：`npm install && npm run build`（需 Node.js 18+）

> ⚡ 已优化：
> - **流式流水线**：边播放视频边抓帧边推理，不再逐帧 seek（内存从 GB 级降到 KB 级）
> - **Worker 池并行推理**：多核并行跑 ONNX，自适应播放速率保证采样密度，
>   18.6s 视频全流程约 60 秒（单线程约 200 秒）；界面可选「快速 · 并行」/「精确 · 逐帧」模式
> - **纯 JS 训练**：3→32→16→1 MLP + Adam，200 轮 <1 秒，无 TensorFlow.js 依赖
> - **完全离线**：wasm 与模型均本地化（assets/wasm/），无需 CDN

## 🎯 功能特点

### 核心流程
1. **视频上传** - 支持MP4格式，拖拽或点击上传
2. **物体识别** - YOLOv8-Tiny识别红色指针和绿色5cm标尺
3. **坐标系标定** - 第一帧指针为原点，右手坐标系
4. **数据采集** - 逐帧采集，生成[t, x, y]时序数据
5. **数据预处理** - 3σ去异常、线性插值、镜头误差修正、归一化
6. **神经网络训练** - 32/16全连接+ReLU，Adam优化，200轮
7. **振动参数计算** - 平衡位置、对数衰减率、阻尼比、阻尼系数、停止时间
8. **可视化展示** - 振动曲线、Loss曲线、时间查询

### 技术参数
- 识别置信度阈值：≥0.25（若模型为动态输入尺寸，自动启用 640 快速路径 + 置信度不足时 1280 复查；固定尺寸模型直接使用模型尺寸）
- 比例尺计算：scale = 5 / gw (cm/px)
- 网络结构：输入3维 → 32 → 16 → 输出1维（纯 JS 实现，无 tfjs 依赖）
- 训练参数：Adam、200轮、batch=16、lr=0.001
- 帧采样：每 3 帧采样 1 帧（快速模式由 Worker 池吞吐 + 自适应播放速率决定，精确模式为严格 10Hz）
- 推理：4 个 Worker 并行（按硬件线程数自适应），本地 wasm，可离线

## 📋 用户操作步骤

1. **上传MP4视频**
   - 点击上传区域或拖拽MP4视频文件
   - 等待视频加载完成

2. **开始分析**
   - 点击【开始识别分析】按钮
   - 等待自动完成全流程：识别→标定→采集→训练→绘图→出报告

3. **查看结果**
   - 实时数据区域显示振动参数
   - 振动曲线图展示原始数据、拟合曲线、预测曲线
   - Loss曲线图展示训练过程

4. **时间查询**
   - 在时间查询输入框输入时间（秒）
   - 点击【查询】或按回车，查看对应时刻的位移

5. **导出报告**
   - 点击【导出报告】按钮
   - 下载JSON格式的分析报告

## ⚠️ 注意事项

1. **浏览器要求**：必须使用 **Chrome 或 Edge 最新版**
2. **模型文件**：需将训练好的 `yolov8-tiny.onnx` 放入 `models/` 文件夹
3. **视频格式**：仅支持MP4格式
4. **识别目标**：视频中需包含红色指针和绿色5cm标尺
5. **性能提示**：大视频会异步处理，可能需要较长时间
6. **错误处理**：识别失败或数据不足会弹窗提示，不会崩溃

## 🔧 技术栈

- **HTML5 + CSS3 + ES6** - 前端基础
- **YOLOv8-Tiny ONNX + WebAssembly** - 物体检测（ONNX Runtime Web，图优化 + SIMD + Web Worker 并行）
- **纯 JavaScript** - 神经网络训练（手写 MLP + Adam，无需 CDN 框架）
- **Math.js** - 数学计算
- **Chart.js** - 图表绘制（暗色主题，默认前5秒视图 + 全览切换）
- **ONNX Runtime Web** - ONNX模型推理（本地 wasm，离线可用）

## 📊 输出参数说明

| 参数 | 说明 | 单位 |
|------|------|------|
| 平衡位置 | 振动稳定后的平衡位置 | cm |
| 阻尼比 | 阻尼系数与临界阻尼系数的比值 | - |
| 阻尼系数 | 振动系统的阻尼系数 | - |
| 周期 | 振动的周期 | s |
| 停止时间 | 振动衰减到阈值以下的时间 | s |
| 对数衰减率 | 相邻振幅比的自然对数 | - |
